### Task 2: Add Bundle Size Budget Enforcement
- **ID:** 01-03-02
- **Description:** Create CI script that fails if 3D deps exceed 200KB gzipped or total JS exceeds 500KB gzipped
- **Files Modified:** `package.json` (scripts), `scripts/check-bundle-size.js` (new)
- **Read First:** `package.json`, `vite.config.js`, `.planning/phases/01-foundation/01-CONTEXT.md` (PER-04 budgets)
- **Acceptance Criteria:**
  - `scripts/check-bundle-size.js` reads `dist/stats.html` or `dist/.vite/manifest.json` + gzip sizes
  - Calculates: sum of `@react-three/fiber`, `@react-three/drei`, `three` gzipped sizes
  - Calculates: total JS gzipped size
  - Exits with code 1 if 3D deps > 200KB gzipped OR total JS > 500KB gzipped
  - Logs clear pass/fail message with actual sizes
  - Added to `package.json`: `"check:bundle": "node scripts/check-bundle-size.js"`
  - `npm run build && npm run check:bundle` passes with current baseline

### Task 4: Implement RAF Pause Logic (PerformanceGuard)
- **ID:** 01-03-04
- **Description:** Create `src/components/three/PerformanceGuard.jsx` — pauses render loop when tab hidden or reduced-motion
- **Files Modified:** `src/components/three/PerformanceGuard.jsx` (new), `src/components/three/Canvas3D.jsx`
- **Read First:** `.planning/phases/01-foundation/01-CONTEXT.md` (Decision 8), `@react-three/fiber` `useFrame` docs
- **Acceptance Criteria:**
  - Exports `PerformanceGuard` component wrapping scene children
  - Uses `useFrame((state, delta) => { if (shouldPause) return; })` pattern
  - `shouldPause = document.hidden || reducedMotion.prefersReducedMotion`
  - Listens to `visibilitychange` event to resume/pause
  - Listens to `reducedMotion` context changes
  - When paused: `state.clock.stop()` or skip frame; when resumed: `state.clock.start()`
  - No-op when 3D not mounted (guard in `Canvas3D`)
  - Logs: `[Perf] RAF paused/resumed — hidden: X, reduced-motion: Y`
