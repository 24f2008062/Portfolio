# Phase 1 Plan 01-02: WebGL Detection + Reduced-Motion Gate + Static Fallback

**Phase:** 1 (01-foundation)
**Plan:** 01-02
**Status:** Pending
**Requirements:** FND-02, FND-03, FND-06, ACC-02

---

## Objective

Implement WebGL support detection, `prefers-reduced-motion` gate, and the static fallback component. The Canvas3D only mounts when: WebGL supported AND user prefers motion. Otherwise, the existing terminal panel renders as a zero-CLS fallback.

---

## Tasks

### Task 1: Create useWebGLSupport Hook
- **ID:** 01-02-01
- **Description:** Create `src/hooks/useWebGLSupport.js` — detects WebGL2/WebGL1 availability
- **Files Modified:** `src/hooks/useWebGLSupport.js` (new)
- **Read First:** `.planning/phases/01-foundation/01-CONTEXT.md` (Decision 3), `src/context/ThreeDContext.jsx`
- **Acceptance Criteria:**
  - Exports `useWebGLSupport()` hook returning `boolean`
  - Creates offscreen canvas: `document.createElement('canvas').getContext('webgl2') || getContext('webgl')`
  - Runs once on mount, memoizes result
  - Handles SSR: returns `false` on server, detects on client in `useEffect`
  - No external dependencies

### Task 2: Create useReducedMotion Hook
- **ID:** 01-02-02
- **Description:** Create `src/hooks/useReducedMotion.js` — reactive `prefers-reduced-motion` listener
- **Files Modified:** `src/hooks/useReducedMotion.js` (new)
- **Read First:** `.planning/phases/01-foundation/01-CONTEXT.md` (Decision 4), `.planning/REQUIREMENTS.md` (FND-02, FND-06, ACC-02)
- **Acceptance Criteria:**
  - Exports `useReducedMotion()` hook returning `boolean` (`true` = reduced motion preferred)
  - Uses `window.matchMedia('(prefers-reduced-motion: reduce)')`
  - Initial value from `mediaQuery.matches`
  - Adds `change` event listener for runtime updates
  - Cleans up listener on unmount
  - SSR-safe: returns `false` on server, hydrates on client

### Task 3: Update ThreeDContext with Detection Logic
- **ID:** 01-02-03
- **Description:** Wire hooks into `ThreeDProvider`, compute `shouldRender3D`
- **Files Modified:** `src/context/ThreeDContext.jsx`
- **Read First:** `src/context/ThreeDContext.jsx`, `src/hooks/useWebGLSupport.js`, `src/hooks/useReducedMotion.js`
- **Acceptance Criteria:**
  - Provider uses both hooks internally
  - `shouldRender3D = webglSupported && !prefersReducedMotion`
  - Context value updates reactively when hooks change
  - `prefersReducedMotion` exposed for global consumers (project cards, scroll stages)
  - No re-renders if values unchanged (memoized)

### Task 4: Create Fallback3D Component
- **ID:** 01-02-04
- **Description:** Create `src/components/three/Fallback3D.jsx` — static terminal panel fallback
- **Files Modified:** `src/components/three/Fallback3D.jsx` (new)
- **Read First:** `src/components/hero/TerminalPanel.jsx`, `.planning/phases/01-foundation/01-CONTEXT.md` (Decision 5)
- **Acceptance Criteria:**
  - Renders `<TerminalPanel />` inside container matching Canvas3D dimensions
  - Container: `position: absolute; inset: 0; width: 100%; height: 100%; z-index: 0;`
  - No Canvas, no WebGL, no animation — pure HTML/CSS
  - Identical visual output to TerminalPanel in Hero
  - Accessible: `aria-hidden="true"` on decorative elements, panel has `aria-label`

### Task 5: Update Canvas3D ErrorBoundary + Fallback
- **ID:** 01-02-05
- **Description:** Wire Fallback3D into Canvas3D's Suspense fallback and ErrorBoundary fallback
- **Files Modified:** `src/components/three/Canvas3D.jsx`
- **Read First:** `src/components/three/Canvas3D.jsx`, `src/components/three/Fallback3D.jsx`
- **Acceptance Criteria:**
  - `<Suspense fallback={<Fallback3D />}>` — shows terminal panel while 3D loads
  - `<ErrorBoundary fallback={<Fallback3D />}>` — shows terminal panel on WebGL context loss/error
  - Fallback3D receives no props (self-contained)
  - Transition: no flash, no layout shift (same container dimensions)

### Task 6: Add Global ReducedMotionContext
